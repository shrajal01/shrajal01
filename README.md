## Selected Projects

### [JakRif Sentinel](https://github.com/shrajal01/jakrif-sentinel) — Payment Reliability Platform

A fault-tolerance-focused payment backend built around the assumption that external payment dependencies can fail.

- Implemented idempotency to make payment requests safer to retry.
- Built asynchronous payment processing with RabbitMQ and a separate worker.
- Added exponential backoff with jitter and dead-letter handling for failed jobs.
- Used correlation IDs to trace a payment across API and worker execution.
- Built a dashboard to inspect payment and retry activity.

**Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, RabbitMQ, Redis, Next.js, TypeScript

### [Flux](https://github.com/shrajal01/flux) — Real-Time Messaging Platform

A full-stack messaging application with persistent conversations and live communication.

- Built REST APIs and persistent WebSocket messaging with FastAPI.
- Implemented direct and group conversations, message persistence, and delivery/read states.
- Used PostgreSQL for durable data and Redis for online presence and pub/sub.
- Built the frontend with Next.js and TypeScript.

**Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, Redis, WebSockets, Next.js, TypeScript

### [Cache Stampede Lab](https://github.com/shrajal01/cache-stampede-lab) — Backend Performance Experiment

A reproducible benchmark comparing strategies for handling cache stampedes under concurrent load.

- Compared naive TTL caching, single-flight request coalescing, and probabilistic early refresh.
- Exercised the service at concurrency levels from 10 to 500.
- Measured origin requests, cache hit rate, and P50/P95/P99 latency.

**Stack:** Python, FastAPI, asyncio, httpx
