## Featured Projects

### 🔧 [Zenith Orchestrator](https://github.com/shrajal01/zenith-orchestrator) — Distributed Task Processing System · [Live](https://zenith-orchestrator.netlify.app)

> Most task queue tutorials stop at "hello world". This one doesn't.

A production-grade distributed backend built to solve real infrastructure problems — not just run examples.

- Celery workers with `concurrency=10`, 3x retry + exponential backoff, dead-letter queue (DLQ)
- Redis-backed sliding window rate limiting — 5 tasks/60s per user
- Real-time WebSocket dashboard with auto-reconnect and live analytics (success rate, throughput, avg. processing time)
- Full Docker Compose infrastructure; deployed on Render

### 🎮 [LexiRush](https://github.com/shrajal01) — Real-Time Multiplayer Vocabulary Platform · [Live](https://lexirush.netlify.app) · Patent Filed
